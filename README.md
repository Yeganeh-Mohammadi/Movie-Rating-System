# 🎬 سامانه مدیریت و امتیازدهی فیلم (Movie Rating System)

این پروژه یک API قدرتمند برای مدیریت بانک اطلاعاتی فیلم‌ها است که با استفاده از **FastAPI** و **PostgreSQL** توسعه یافته است. این سامانه به کاربران اجازه می‌دهد فیلم‌ها را مشاهده کنند، به آن‌ها امتیاز بدهند و اطلاعات مربوط به کارگردانان و ژانرها را مدیریت کنند.

---

## 👥 تیم توسعه و تفکیک وظایف

پروژه به صورت تیمی توسعه یافته و وظایف به شرح زیر تقسیم شده است:

### 🛠 وظایف انجام شده توسط یگانه:
* طراحی و پیاده‌سازی مدل‌های اصلی پایگاه داده (Models).
* پیاده‌سازی قابلیت **ثبت فیلم جدید** به همراه ارتباط با ژانرها.
* پیاده‌سازی سرویس **لیستینگ فیلم‌ها** با قابلیت فیلتر پیشرفته (بر اساس نام، سال تولید و ژانر).
* طراحی و پیاده‌سازی **سیستم امتیازدهی (Rating)** و ثبت نظرات کاربران.
* پیاده‌سازی منطق محاسباتی برای نمایش **میانگین امتیازات** هر فیلم در خروجی.

### 🛠 وظایف انجام شده توسط نازدانه
 طراحی و پیاده‌سازی مدل‌های اصلی پایگاه داده (Models).
*  طراحی و پیاده‌سازی سیستم **مدیریت کارگردانان** (ثبت و مشاهده بیوگرافی).
* پیاده‌سازی زیرساخت **ژانربندی فیلم‌ها** (ایجاد و مدیریت دسته‌ها).
* پیاده‌سازی سیستم **ثبت‌نام و مدیریت کاربران**.
* تکمیل لایه‌های Repository و Controller برای بخش‌های مرتبط با کاربران و کارگردانان.

---

## 🚀 قابلیت‌های کلیدی برنامه

* **مدیریت جامع فیلم‌ها:** امکان ثبت، مشاهده لیست و مشاهده جزئیات هر فیلم.
* **فیلترینگ هوشمند:** جستجوی فیلم‌ها بر اساس پارامترهای مختلف.
* **سیستم تعاملی امتیازدهی:** امکان ثبت نمره (۱ تا ۵) و نظر توسط کاربران.
* **محاسبه آنی میانگین:** نمایش خودکار نمره نهایی فیلم بر اساس نظرات ثبت شده.
* **ارتباطات دیتابیسی (ORM):** استفاده از روابط Many-to-Many برای ژانرها و One-to-Many برای امتیازها.
